# Maintenance Ticket Triage

> Every ticket routed right, the first time

AI that classifies, prioritizes and routes incoming maintenance tickets to the right team with the right parts.

**Live:** https://ziontechgroup.com/maintenance-ticket-triage/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- Auto-classification by asset, failure mode and urgency
- Duplicate detection and ticket merging
- Skill- and location-based assignment
- Parts pre-pick suggestions via Spare Price Scout
